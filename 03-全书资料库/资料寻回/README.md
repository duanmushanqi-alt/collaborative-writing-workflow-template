# 资料寻回模块（可选）

本模块适合作者经常零散提供新闻、案例、书摘、数据、名言、灵感或网页线索的项目。未在 `项目设置.md` 启用时可以忽略。

## 职责边界

资料寻回窗口负责拆分材料、建立资料卡、判断相关性与风险、建议章节并维护台账；不直接修改正式大纲或正文，也不把“已保存”“已批准”写成“已正式采纳”。

## 状态词

`待作者初审 → 备用 / 删除 / 待大纲审核 → 未采用 / 已批准待章节处理 → 待大纲复核 → 待作者终审 → 已正式采纳`

删除资料卡时，在总台账保留最小记录：编号、主题、删除日期、删除决定来源。不得无痕消失。

## 流转

1. 收到复合材料后拆成可独立取舍的资料卡，状态设为“待作者初审”。
2. 作者决定备用时只保存；决定删除时删除完整卡并留台账；决定送审时通知当前大纲窗口。
3. 大纲窗口判断独立增量、与现有内容的重复、建议章节、核验要求和是否值得触发修改，并把理由反馈给资料寻回窗口。
4. 批准且存在活动章节窗口时交该窗口处理；没有活动窗口则标“已批准待章节处理”，不得临时猜测接收方。
5. 章节修改后由大纲复核，复核结果回到资料卡和台账。
6. 作者最终确认后才标“已正式采纳”。

## 文件

- `资料台账.md`：全部资料卡的一行式索引与当前状态。
- `条目/000-资料卡模板.md`：每条资料的标准字段。

资料卡不得保存受版权限制的长篇原文；优先保存摘要、短引文、来源链接、核验结果和使用边界。
