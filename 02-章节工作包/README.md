# 章节工作包说明

本文件只说明章节目录包含什么。所有先后顺序、窗口通知和作者动作，以 `00-项目管理/协作流程.md` 为唯一权威。

## 标准七类文件

```text
第X章/
  章节要求.md
  参考资料.md
  方案审核单.md
  外部AI提示词.md
  章节正文.md
  正文审核记录.md
  章节回填.md
```

1. `章节要求.md`：章节功能、必写内容、避让内容、资料、风格和完成标准。
2. `参考资料.md`：已核验、待核验、线索、排除项及实际使用边界。
3. `方案审核单.md`：只保存方案与资料审核意见和处理结果。
4. `外部AI提示词.md`：方案通过后生成的初稿或返修提示词；不保存AI回答。
5. `章节正文.md`：当前认可的完整正文，只保留一个当前版本。
6. `正文审核记录.md`：初稿分级验收、作者审读和正文终审的历史与结论。
7. `章节回填.md`：完成后的实际路径、方案差异、资料核验和后章避让。

未启动章节不提前制造空文档；启动时复制 `00-章节模板/`。已有目录只核对、不覆盖。

## 流程摘要

`要求与资料讨论 → 方案审核通过 → 生成并轻检提示词 → 接收初稿 → A/B/C验收 → 作者审读 → 正文终审 → 回填、经验、状态关闭 → Git恢复点`

当前阶段只认 `00-项目管理/项目状态.md`。章节文件中的状态文字属于历史，不得覆盖唯一状态看板。

## 关闭前强制检查

- [ ] 七类文件齐全，方案审核与正文审核未混写
- [ ] 章节正文是唯一当前认可稿，过程稿已覆盖或归档
- [ ] 资料来源、使用边界和待核验事项已回填
- [ ] 正式大纲、简版大纲、写作规范和项目决策已按需同步
- [ ] 经验复盘已提交并回读；无新增时已明确记录
- [ ] 项目状态已更新为“已关闭”
- [ ] 本次章节相关改动已建立可恢复版本并上传
