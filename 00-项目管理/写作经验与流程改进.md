# 写作经验与流程改进

本文件保存可复用经验，不保存普通讨论，也不替代正式大纲、写作规范或章节文件。

## 管理原则

1. 章节窗口、大纲窗口和其他专项窗口负责发现并简要记录。
2. 项目管理窗口负责去重、归类、验证、冲突检查和落地。
3. 第一次出现进入待观察，不立即改变正式流程。
4. 第二次出现或已造成明显损失进入待确认。
5. 只有经过验证并写入正式文件的做法才算已固化。
6. 与旧规则冲突时不直接覆盖，先进入冲突待裁定。
7. 没有新增经验时不强行总结。

## 已固化

### 2.0.0升级｜统一七类章节文件与灵活正文生产

- 类型：协作流程
- 经验或建议：每章统一使用七类正式文件。正文可以交外部AI、其他写作者或内部专项窗口生产，由章节窗口保存当前认可稿并完成A/B/C验收；不为窗口分工额外制造必须长期维护的过程文件。
- 适用范围：所有章节
- 来源窗口：模板设计
- 成熟度：已固化
- 落地位置：协作流程、章节工作包、AGENTS.md

### 2.0.0升级｜方案、提示词与正文分段审核

- 类型：审核经验 / 文件管理
- 经验或建议：方案审核只处理章节要求与资料，提示词在方案通过后只做一次轻量差异检查，正文审核记录承载初稿验收、作者审读和正文终审；三者不得混写。
- 适用范围：所有章节
- 来源窗口：多章节协作验证
- 成熟度：已固化
- 落地位置：协作流程、方案审核单、外部AI提示词、正文审核记录

### 2.0.0升级｜章节关闭自动形成恢复点

- 类型：协作流程 / 文件管理
- 经验或建议：正文终审通过后自动完成回填、全书同步、经验提交与回读、唯一状态关闭，再由项目管理窗口只提交本章关闭相关改动并上传恢复版本。
- 适用范围：章节关闭、结构大改和阶段复盘
- 来源窗口：多章节恢复点实践
- 成熟度：已固化
- 落地位置：协作流程、章节回填、README

### 模板初始规则｜唯一状态源

- 类型：文件管理
- 经验或建议：当前项目状态只写入项目状态文件，审核文件和回填只保存结论与历史。
- 适用范围：所有窗口
- 来源窗口：模板设计
- 成熟度：已固化
- 落地位置：项目状态、AGENTS.md

### 1.0.1兼容修订｜责任窗口直接创建下游窗口

- 类型：协作流程
- 经验或建议：启动章节由当前责任窗口创建章节工作包和章节窗口；长期窗口由当前责任窗口创建自己的接班窗口。项目管理窗口只负责初始化、恢复点、一致性、经验和异常恢复，不作为日常中转站。1.0.1中“章节窗口必须创建正文写作窗口”的部分已由2.0.0替代，正文生产方式改为项目可选。
- 适用范围：所有章节和长期窗口换代
- 来源窗口：模板流程修订
- 成熟度：部分已失效；窗口接班规则继续有效
- 落地位置：README、协作流程、AGENTS.md、项目启动清单、窗口登记；正文窗口部分见2.0.0迁移说明
