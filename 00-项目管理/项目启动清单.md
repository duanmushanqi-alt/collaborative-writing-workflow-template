# 项目启动清单

本清单只在从模板生成一本新书项目时执行一次。

## 一、确认项目身份

- [ ] 确认这是从模板生成的新仓库，而不是上游模板仓库
- [ ] 将项目模式改为“正式项目”
- [ ] 填写项目名称、作品名称、作者或主创
- [ ] 记录采用的模板版本
- [ ] 确认本地工作目录和版本仓库

## 二、建立协作窗口

- [ ] 登记项目管理窗口
- [ ] 建立并登记当前大纲窗口
- [ ] 明确作者是最终内容决策者
- [ ] 确认正文写作窗口按章节建立，不提前批量创建

## 三、建立全书控制文件

- [ ] 完成项目定位
- [ ] 建立第一版正式大纲
- [ ] 建立简版大纲
- [ ] 与作者确认写作规范
- [ ] 确认资料核验与引用原则

## 四、建立项目状态

- [ ] 在项目状态中登记全书任务
- [ ] 登记准备启动的第一章或第一个写作单元
- [ ] 写明下一动作和责任窗口
- [ ] 确认没有其他文件承担当前状态看板

## 五、保存初始化版本

- [ ] 检查项目中不含模板示例之外的无关内容
- [ ] 保存初始化完成后的恢复版本
- [ ] 确认远程备份可用

全部完成后，项目管理窗口回复：

> 新书项目初始化完成，可以启动第一个写作单元。
