# 从1.x迁移到2.0

本说明只用于已有1.x项目。新项目直接使用2.0七类文件。

## 文件映射

| 1.x文件 | 2.0处理 |
|---|---|
| `写作协作/正文写作任务单.md` | 整理为顶层 `外部AI提示词.md` |
| `写作协作/正文工作稿.md` | 当前认可内容并入 `章节正文.md`；其余按需归档 |
| `写作协作/正文审核记录.md` | 移到章节目录顶层 |

## 状态映射

| 1.x状态 | 2.0状态 |
|---|---|
| 方案修改中 | 待方案审核 |
| 方案已通过、写作任务待检查 | 方案通过 |
| 正文写作中 | 提示词通过 |
| 初稿待验收、A级重写、B级返修 | 初稿验收 |
| C级可审读、作者审读中 | 作者审读 |
| 正文终审修改中 | 待正文终审 |
| 待章节关闭 | 待正文终审，直至关闭事项全部完成后改为已关闭 |

## 安全步骤

1. 先建立迁移前恢复点。
2. 逐章迁移，不批量覆盖已有正文。
3. 保留有追溯价值的审核历史，删除竞争性的当前状态。
4. 核对每章七类文件和唯一状态看板。
5. 迁移完成后建立新的恢复点并记录采用模板版本。
