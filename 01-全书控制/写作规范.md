# 写作规范

本文件保存全书通用、已经确认的写作约束。单章要求写入对应章节工作包。

## 一、作者声音

- 叙述距离：
- 人称使用：
- 句子节奏：
- 幽默或情绪强度：
- 作者常用但希望保留的表达：
- 容易出现但应减少的表达：

## 二、结构原则

1. 每章先固定三至五句话的因果链，再润色句子。
2. 每节只承担一个主要任务。
3. 一个关键转折只完整完成一次。
4. 每节必须比上一节新增判断、机制、证据或行动。
5. 章末只完成本章，不用重复总结换取篇幅。
6. 字数服从章节功能，不用近义案例和重复结论补字。

## 三、资料和事实

1. 资料必须区分已核验、待核验、线索和排除项。
2. 正文中的事实边界写进具体措辞，不连续堆叠免责声明。
3. 单一案例不能自动代表普遍规律。
4. 个人经验可以证明“曾经这样发生”，不能单独证明“所有人都如此”。
5. 不猜测姓名、题名、数字、出处或因果关系。
6. 每项核心材料要有明确的主要证明任务和主场章节。

## 四、正文生产要求

1. 正文初稿必须以通过方案审核并完成轻量检查的提示词为依据。
2. 不擅自增加新的核心观点、人物经历或事实材料。
3. 不虚构作者经历、研究结论、对话、数据和完整人物履历。
4. 假设情境必须短小，并明确其假设性质。
5. 不把提示词、审核要求或编辑说明直接抄进正文。
6. 初稿必须是完整正文，不输出创作解释、致歉或自评。

## 五、修改原则

1. 修改前读取当前文件，不以对话中的旧文本为准。
2. 写入后回读修改位置和上下文。
3. 结构问题优先于句子润色。
4. 作者确认的个人事实和核心表达不得自行改写含义。
5. 删除重复后先检查功能是否缺失，不按原字数机械补回。
